#Overview
This project demonstrates an automated API testing and CI/CD pipeline using:

Postman -> for designing and running API test collections

Newman -> for executing Postman collections via CLI

Jenkins -> for automating test runs in a CI/CD pipeline

JSON Server -> for simulating a mock REST API

JSON Authentication -> for handling secure endpoints with token-based authentication

#Project Structure

├── postman_collections/   
Postman collections & environments

├── newman_reports/        
 Newman HTML/JSON reports
 
├── jenkins_pipeline/     
 Jenkinsfile & pipeline configs
 
├── json-server/          
 Mock API setup
